# 小米手环 10 Pro 336x480 适配设计

## 目标

将应用的设备基准从 `212x520` 调整为小米手环 10 Pro 与 9 Pro 共用的 `336x480` 竖屏尺寸，同时保留现有剧情、存档协议和 PNG 图片资源。

## 范围

- `src/manifest.json` 的 `designWidth` 改为 `336`。
- 首页、阅读器、设置、存档和关于页使用固定的 `336px` 宽、`480px` 高画布。
- 按更宽、略矮的屏幕重新布置按钮、对话区、弹窗和预览区，保持原有导航与点击行为。
- 阅读器背景与 CG 继续使用现有资源；横向背景滚动终点由图片宽度与 `336px` 可视宽度计算，避免保留只适合 `212px` 的硬编码距离。
- 现有背景、CG、立绘、剧情分块和存档数据不重制、不迁移。

## 不在范围内

- 不批量裁切或生成新的图片资源。
- 不修改剧情文本、路由、存档键或应用版本号。
- 不打包 APK/RPK；本次不触发 `versionCode` 递增规则。

## 实现方式

页面继续使用当前 UX 固定像素布局，不引入缩放容器或响应式分支。横向空间按 `336px` 宽重新分配，纵向内容压缩到 `480px`，以确保首页操作、阅读对话、选项和菜单均在单屏内可操作。背景图保持 `692px` 宽，阅读器横移距离使用 `692 - 336 = 356px`；纵向背景和 CG 继续按既有图片尺寸显示与裁切。

## 验收

- 所有五个页面的根画布均为 `336px x 480px`，清除对 `212px x 520px` 的布局断言。
- `designWidth` 为 `336`。
- 首页、设置、存档、关于页和阅读器的核心交互仍使用原有事件和路由。
- 阅读器的横向背景滚动不超出图片边界，运行时不使用动画 CSS 或 Folme。
- `npm test` 与 `npm run validate:story` 通过。
