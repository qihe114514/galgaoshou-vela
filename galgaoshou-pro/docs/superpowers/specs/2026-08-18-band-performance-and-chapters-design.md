# 手环性能、资源与分章设计

## 目标

降低全剧情 RPK 的资源体积与真机解码压力，修复文字交互问题，并为完整剧情提供安全的自动分章与章节跳过。

## 资源策略

- 所有资源继续使用 PNG，禁止输出 JPG/JPEG。
- 手机界面 (`centerOverlay`) 导出为 256 色高质量调色板 PNG；保留 `256x405` 画布和文字可读性。
- 背景与 CG 使用调色板 PNG；立绘、立牌保留透明通道。
- 只对无文字背景进行近似重复检测。候选图必须同尺寸、像素差低于保守阈值，随后由转换器把后续引用改为保留图；CG、手机图、日期和叠图不参与近似合并。
- 立绘和立牌在导出画布内下移 30px，仍由播放器以 `212x520` 底部对齐显示。

## 播放器性能与交互

- 首页背景在图片 `complete` 后再启动 Folme 横移，图片加载失败时保留粉色主题底色并停止动画。
- 剧情播放器维持当前块与一个相邻分块的缓存。进入缓存块不再读盘或 JSON 解析；进入新块后后台预读下一顺序块。
- 场景切换只在背景资源或运动类型改变时替换背景；相同背景继续使用现有图层与横移状态。
- `textSpeed: 0` 表示立即显示完整文本，不能回退到默认速度。
- 打字机未结束时点击屏幕直接显示完整当前文本；文本完整后才进入下一句。

## 自动分章

- 转换器生成章节索引，章节边界来自稳定的剧情大段落入口和选择节点。
- 每个章节入口必须是可达节点，且不会跳过未选择的必经选择点。
- 存档保存章节号，同时继续以全局场景号作为兼容读取主键。
- 菜单“跳过章节”只跳到当前路线的下一个安全章节入口；没有可安全跳过的入口时提示用户。

## 验收

- 手机图抽样在真机上可读，且资源体积明显低于现有无损 RGBA 版本。
- 主界面图片完成加载后才开始滚动；缺图不造成灰屏或无响应。
- 文字速度为 `0` 时不启动字符定时器，点击未完成文字会直接补全。
- 相邻剧情块切换不发生同步文件读取；当前背景未改变时不重启动画。
- 自动章节索引全部可达，跳章不跨越选择节点；旧存档可继续读取。
- 完整校验、测试和 RPK 构建通过；最终打包时递增 `versionCode`。
