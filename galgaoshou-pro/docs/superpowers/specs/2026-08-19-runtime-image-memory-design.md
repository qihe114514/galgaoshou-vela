# 运行时图片驻留优化设计

## 目标

在不缩放或压缩背景、角色图的前提下，保持无闪烁的场景切换，并在设备发生内存重启后恢复最近阅读进度。

## 方案

- 场景切换直接替换背景、CG、角色和 overlay 图片字段，避免先卸载再挂载造成闪烁。
- 剧情缓存保留当前块和下一块，跨块时提前读取下一块以保持连续阅读。
- 每显示 10 段新的对白后，将既有存档数据结构覆盖写入独立 `autoSave` 键；恢复存档时重新显示的当前对白不计入次数。
- 存档页在手动存档 1 前固定显示独立的“自动存档”行。读取页可读取有效自动存档，保存页不可操作，自动存档不可覆盖、不可删除且不占用手动槽位。
- 主页只使用有效的 `autoSave` 继续阅读；自动存档缺失或损坏时从序章开始，不回退到手动存档。
- 手动存档长按删除会消费同一手势随后派发的点击事件，松手后保持删除确认框而不读取或覆盖存档。

## 约束与验证

- 背景图、角色图的分辨率、格式和压缩参数保持不变。
- 不新增运行时依赖。
- 通过单元测试、故事资源校验和构建验证；最终在真机连续推进高频换图剧情至少 30 分钟，确认无闪烁、自动存档可恢复，并检查无堆分配失败和 PMU 重启日志。
