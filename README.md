# 难道你是GAL高手 · 小米手环9

面向小米 Vela 设备（手环 / 手表）的 GAL 游戏播放器移植，按设备分分支维护。
本分支对应 **小米手环9**，默认分支为 **小米手环10**。

本分支包含两个版本：

| 目录 | 版本 | 说明 |
| --- | --- | --- |
| `galgaoshou/` | 完整版 | 完整剧情 |
| `galgaoshou-trial/` | 试玩版 | 精简剧情 |

## 快速开始

1. 进入对应版本目录：`cd galgaoshou` 或 `cd galgaoshou-trial`。
2. 安装依赖：`npm install`。
3. 运行校验：`npm run check`。
4. 在 AIoT-IDE 中打开该目录，或运行 `npm run start`。
5. 构建：`npm run build`（完整版会先执行 `optimize:home` 再调用 aiot 打包）。
